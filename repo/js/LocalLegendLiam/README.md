# Local Legend: Liam Guide

This script challenges and defeats the Local Legend "Liam".

## Important Notes:
1. **Loot Pickup**: Without Kaedehara Kazuha, picking up drops in the water is difficult. Ensure you have Kaedehara Kazuha in slot 3 of the party, or uncheck the auto-loot option!
2. **Team Lineup**:
   - Slot 1: Tighnari (or Amber; other non-Hydro bow users work).
   - Slot 2: Zhongli (strongly recommended for shields; success rate >74%! Noelle can be used as fallback but has lower success rate).
   - Slot 3: Kaedehara Kazuha (for vacuuming drops).
3. **Prerequisite**: Please make sure the pond puzzle is unlocked beforehand.
