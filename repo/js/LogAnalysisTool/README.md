# BetterGI Log Analysis Tool

A web-based tool for analyzing Better Genshin Impact automation logs, featuring drag-and-drop operations, multiple display modes, and rich keyboard shortcuts.

**Live URL**: https://this-fish.github.io/Read_BetterGI_Log/index.html

## 🌟 Core Features

### Log Parsing
- 📁 **Drag-and-Drop Analysis** - Drag and drop log files directly onto the page to inspect.
- 📱 **Mobile Support** - Dedicated upload interface optimized for phone/tablet devices.
- 🔄 **Multi-file Merging** - Automatically merges multiple log files chronologically.
- ⏰ **Smart Timestamp Parsing** - Seamlessly handles cross-day log boundaries and timing calculations.

### Data Visualization
- 📊 **Detailed Statistics** - Comprehensive metrics on revivals, retries, and stuck coordinates.
- 🎯 **Coordinate Tracking** - Pinpoints last recorded X/Y world coordinates prior to character defeat.
- ⚡ **Real-time Highlighting** - Hover row highlighting for easy tracing.
- 🌓 **Theme Toggle** - Supports light and dark mode toggles.

### Navigation and Shortcuts
- Use arrow keys or scroll to quickly browse through execution events.
- Filter logs by error level, script type, or timestamp range.
