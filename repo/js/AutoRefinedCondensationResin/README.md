# Auto 合成Condensed Resin脚本

## Features特点
1. **多国合成台Supports**：可Go toMondstadt/Liyue/Inazuma/Fontaine合成台
2. **智能时间判定**：
   - 00:00~04:00 视为前一天
   - Auto 适应游戏内时间机制
3. **灵活执行Settings**：
   - Supports每日Auto 执行
   - 可指定每星期特定星期几执行

## 参数Guide / Instructions
| 参数名     | 类型       | Guide / Instructions                                                                 |
|------------|------------|----------------------------------------------------------------------|
| **合成台位置**   | 下拉选择   | 可选：Mondstadt/Liyue/Inazuma/Fontaine<br>默认：Liyue合成台      |
| **指定执行星期**       | 勾选   | 勾选星期一~星期日 |
