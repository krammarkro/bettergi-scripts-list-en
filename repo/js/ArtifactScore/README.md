# Real-Time Artifact Scoring

Displays artifact ratings in real-time on the character's Artifact screen in Genshin Impact.

> Ready to use out of the box.

## Preview

<img src="assets/images/readme/show.webp" style="width: 60%" alt="Artifact Score Preview"/>

## Requirements

- BetterGI version `0.61.0` or higher.
- In-game language set to Simplified Chinese.
- Recommended resolution: `1920×1080`, 16:9 aspect ratio, default UI scale.

## Usage Instructions

1. Start the "Real-Time Artifact Scoring" script.
2. Open the Artifacts page on the Character screen as shown:  

<img src="assets/images/readme/role.webp" style="width: 80%" alt="Character Artifact Page"/>

3. Wait a moment, and the score overlay will appear automatically.
4. When switching artifacts, the script will re-identify the slot and affixes, updating the score accordingly.

To stop using it, press the Stop Script hotkey in BetterGI.

## Two Scoring Modes

### Character-Targeted Scoring

Before entering details, the script attempts to identify and cache the current character. It supports the following title formats:

- `Hydro / Sangonomiya Kokomi`
- `Artifacts / Sangonomiya Kokomi`

<img src="assets/images/readme/get-role.webp" style="width: 80%" alt="Identify Character"/>

Once successfully recognized, the large score in the floating window will display as "Character Name: Score". This score is calculated based on the character's effective stats, element, and special scoring rules.

The Traveler is differentiated by element (Anemo, Geo, Electro, Dendro, Hydro, Pyro) and will appear in rankings as "Traveler (Element)".

### General Scoring

If you directly enter the artifact details page and no preceding character is recognized, the floating window displays a general score.

General scoring does not just evaluate CRIT Rate and CRIT DMG. The script evaluates the artifact's score across all characters and takes the average of the top 50%; effective affixes such as ATK, HP, DEF, Elemental Mastery, Energy Recharge, and CRIT are all factored into the calculation.

## Overlay Window Content

- Large Number: Targeted score for the current character, or general score if no character is cached.
- Tier Rating: `D`, `C`, `B`, `A`, `S`, `SS`, `SSS`, `ACE`, `MAX`.
- Recognized Affixes: The main stat and 4 sub-stats passed to the scoring engine.
- Best Fit Characters: Top 10 characters with the highest score for this artifact.

Lines that cannot be reliably parsed will appear in red as "Unrecognized / --". If an error occurs, wait a moment or switch to another artifact and back.

> Sub-stat roll counts are purely estimated from the final value and may not reflect actual enhancement history.

## Scoring Data

Scoring weights and character-specific rules are derived from [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin). Scores are intended for quick filtering and reference only, and do not represent the sole build conclusion; actual artifact value is influenced by team comp, weapon, constellations, and playstyle.

## Developer Notes

The scoring rules module `utils/artis-score-standalone.js` is fully generated by the following command; do not edit the generated file directly:

```bash
node tools/crawl-standalone.js
```

You can use `--branch` to specify the miao-plugin branch. This crawler is solely used to update character scoring rules, weights, base stats, and special rules from miao-plugin.

Individual affix score breakdowns, effective/ineffective stat highlighting, and roll count estimations are maintained in `utils/artis-score-utils.js` and are kept separate from crawler templates to prevent accidental overwrites during updates.
