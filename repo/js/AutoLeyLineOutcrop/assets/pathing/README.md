# Path追踪脚本录制的Precautions / Notes
## 命名格式
`{国家名}{Route编号}-{第一个花所在的地区名或者Route所在的地区名}-{地脉花编号}`
可重跑Route：
`{国家名}{Route编号}-{第一个花所在的地区名或者Route所在的地区名}-{地脉花编号}-rerun`
## 存放Path
`assets\pathing`
可重跑Route：
`assets\pathing\rerun`
## 录制
- 1号花的第一个点位必须是传送
- 使用target走到地脉花位置
- 后续的花如果从现在的位置走过去更近就直接走，也就是第一个点位不能是传送；如果传送更近就传送；可重跑模式的第一个点位必须是传送
