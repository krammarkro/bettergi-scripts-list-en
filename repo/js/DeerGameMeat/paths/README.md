## Configuration与运行要求

> 虽然全线会路过两只Frostnight Scion，但是不用Combat，都是直接冲过去的哦。

### 🎯 Character要求
- 确保队伍中有「Lauma」与「Kaedehara Kazuha」
- 将`行走位`Settings为「Lauma」

### ⚠️ 运行须知（必看）
- 运行前请确保游戏内Nope, Not In下雨状态，下雨时Nod-Krai的小动物会消失。运行中途若Starting Up下雨，将无法避免地白跑！
- 运行前请确保你今天Nope跑过`Rainbowdrop Crystal`Route和`Frostnight Scion`Route，这两个Route与犀牛Route存在重叠，会导致犀牛跑走。
- 苔古荒原中间的Teleport Waypoint处有一个需要Searching10个机器人才能解锁的飞高高装置，请解锁它，否则请禁用`05`和`07`两条Route。

### 🚀 运行效率
- 11分钟可收获理论最多85个Raw Meat
- 常态下拾取约75个

### ⚔️ 风险点位Guide / Instructions
Path`07-苔古荒原中间-12个`落地点有一只Elite怪，拾取时会触发Combat（不会打，拿完就跑）。  
怕暴毙的可选择性关闭，但这个点位物资丰厚，高风险高回报。
