## Configuration and Execution Requirements

> Although the route passes by two Frostnight Scions, no combat is required; you dash straight past them.

### 🎯 Character Requirements
- Ensure the team includes **Lauma** and **Kaedehara Kazuha**.
- Set the `Runner Character` to **Lauma**.

### ⚠️ Execution Notes (Must Read)
- Ensure it is **NOT raining** in-game before running. Rain causes small animals in Nod-Krai to despawn. If it starts raining midway, the run will unfortunately yield nothing!
- Ensure you have **NOT** run the `Rainbowdrop Crystal` or `Frostnight Scion` routes today; those routes overlap with rhinoceros spawns and will cause them to flee.
- At the central Teleport Waypoint in the Mossy Wasteland, there is a catapult launcher contraption unlocked by finding 10 automatons. Please unlock it beforehand; otherwise, disable routes `05` and `07`.

### 🚀 Farming Efficiency
- Theoretically harvests up to 85 Raw Meat in ~11 minutes.
- Typically collects around 75 Raw Meat under normal conditions.

### ⚔️ Risk Spot Notes
The landing spot of Route `07-苔古荒原中间-12个` contains an Elite enemy, which triggers combat upon landing (the script does not fight, it collects drops and flees immediately).  
Disable this route if you are concerned about sudden character knockouts; however, it contains abundant resources (high risk, high reward).
