# 装备或卸下跟随宠物

## Instructions

### 装备跟随宠物

1. 修改自定义Configuration中模式为：`装备`
2. 修改自定义Configuration中宠物名称
3. 执行脚本即可

### 卸下跟随宠物

1. 修改自定义Configuration中模式为：`卸下`
2. 执行脚本即可

## Precautions / Notes

+ 请在原神分辨率为 1920x1080 下使用该脚本。
