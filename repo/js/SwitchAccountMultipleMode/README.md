## 1.下拉列表模式

### 1.1.使用前准备

确保你想要Switch的Account是已登录状态，且Account选择列表中存在。

### 1.2.使用方式

1. 把此脚本添加到Configuration组
2. 右键点击选择"修改JS脚本自定义Configuration"
3. 填入你想登录的账户名称，该名称必须和Account列表中显示的一致
   - 请确认你此次登录使用的是手机号还是邮箱
