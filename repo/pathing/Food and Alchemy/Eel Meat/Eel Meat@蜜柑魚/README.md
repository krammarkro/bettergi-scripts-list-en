## Path说明

### Path构成
- **Inazuma部分**：主要取自「TeyvatIngredients All-in-One Run」中的 `CInazumaIngredients@MissDan`  
  该Path沿途会采集Other材料，**执行时间会比纯Eel MeatPath稍长**

- **Sumeru、Enkanomiya部分**：主要参考 `Eel Meat@海豹穹穹队` Path修改制作

---

### Precautions / Notes

1. **队伍配置**  
   队伍中必需包含 **Yaoyao / Sayu / Lan Yan** 等不会惊动鳗鱼的角色
   若使用 **Kirara** 或 **Aloy**，还能避免因附近鸟类受惊而连带吓跑鳗鱼

2. **沙漠环境**  
   若使用「沙漠后缀」Path，Recommendation在**沙漠无Sandstorm时执行**，否则可能影响Path正常运作  
   *Recommended配合「采集CD管理」使用*

3. **特殊机制**  
   「Safhe Shatranj」Path中有两条Eel Meat埋在**沙堆**中，需要队伍中有**风系角色**才能采集

4. **操作提醒**  
   执行过程中尽量避免在鳗鱼点附近释放生存位技能，否则**可能导致鳗鱼受惊逃窜**

5. **不可抗力因素**  
   以下情况可能导致鳗鱼受惊逃窜，造成空跑：
   - **Monsters / Enemies镇守的鳗鱼点**（仍可能拾取部分Eel Meat）
   - **下雨天气**（雨水会惊扰鳗鱼）
