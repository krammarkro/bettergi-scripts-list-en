# Pathing Script by WuHu

* Executing in clear weather ensures route recognition success (criterion is clear minimap).
* If there is a sandstorm (minimap is blurred/masked, large sandstorm visible on world map), route recognition is 100% abnormal.

1. Easily affected by low visibility in the Sumeru desert and sandstorms blurring the minimap; minimap frequently fails to be recognized, leading to very low success rate;
   However, no game-locking bugs have been found so far (locking spots were fixed), so it is left as-is.
   Spots with recognition errors might cause falling to low HP and re-attempting several times, which might succeed; if not, skip it. Aside from consuming time, there is no major impact.
2. The only route with a relatively high success rate is "1 Safhe Shatranj".
3. Easy to get knocked away by Wenut, recommend having interruption resistance (shield) in the runner/survival slot.
4. Easy to take fall damage (falling hurts a lot in Sumeru).
