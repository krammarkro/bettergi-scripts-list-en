# 说明

- 不限制配队移动速度（游泳速度），可以用Neuvillette+Dehya+Anemo Resonance提High Efficiency
- Recommendation行走位用血量较高的角色，RecommendedThe BellDehya，避免Mining过程中被打回Statue of The Seven回血失去Crab技能，导致后续不能Mining
- ABCE-开头的Route假设已经习得Crab技能，不按顺序运行或者中途暂停出水面将导致角色失去Crab技能，运行或恢复运行前请确保角色Learning了Crab技能
- A00Route用来Learning大Fontaine湖的Crab技能，E00Route用来LearningSea of Bygone Eras的Crab技能。二者不互通
- D-开头的Route不受上述条件限制，可独立运行
- 如果遇到生存位角色如Zhongli、Citlali等自动开盾导致Crab炸矿技能进入CD的问题，请在配置组设置中修改地图追踪行走配置
