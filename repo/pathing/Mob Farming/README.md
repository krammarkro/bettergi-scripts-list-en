## Mob Farming
> 注：如果你需要更高的效率，请尝试使用 **锄地All-in-One Run** js脚本
### 锄Surface限
每 items人每天最多400 itemsElite怪上限2000 itemsCommon Mobs上限，当到达上限的时候Elite怪不再掉落任何Mora和材料，该上限每天北京时间 4:00 刷新。因此使用此目录下的脚本时，需要注意每日上限，避免超过上限而不产生收益。
### 锄地收益
锄地的主要目的是获取Mora和圣遗物狗粮。
#### 圣遗物收益
Elite400 的Monsters / Enemies死亡时有概率掉落圣遗物，除部分特殊Monsters / Enemies之外，圣遗物掉落的概率为 10%，掉落圣遗物时，出现四星圣遗物的概率为 20%，出现三星圣遗物的概率为 80%。锄满每日上限约获得 40  items圣遗物狗粮。
#### Mora收益
Elite400 中的Monsters / Enemies死亡时会掉落Mora，分为3000Mora，1200Mora，600Mora，400Mora，200Mora档，3000Mora档占用3 itemsElite上限，1200Mora档占用2 itemsElite上限，OtherMora档占用1 itemsElite上限。
#### Drops收益
Elite怪掉落海量Monsters / Enemies素材，但是对于锄地人群是最无用的素材。
