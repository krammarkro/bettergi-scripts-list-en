Test Environment：【1920x1080 窗口】、60帧

Thank You[空荧酒馆](https://yuanshen.site/docs/)的点位信息为我制作地图追踪脚本提供的帮助。

HilichurlShooter：由于HilichurlShooter的位置在高处，导致掉落材料很容易捡不到，请务必在Combat配队里携带一 itemsKaedehara Kazuha或者琴来聚集材料，如有必要请务必在“全自动”->“调度器”->“配置组”->“{你的配置组}”->Top-Right角“设置”中在“Combat配置”下方打开“自动拾取Drops”或者“聚集材料动作”选项，这将能尽可能让Drops被拾取而不是路过就I'm Off。携带Kaedehara Kazuha能够拾取到80%-90%的材料，不携带Kaedehara Kazuha mobs能拾取差不多30%-40%的材料。

注：由本人制作的地图追踪脚本在运行时会提前释放部分角色的元素战技，跟JS脚本【锄地All-in-One Run】的泥头车功能类似，所以请务必在配队里至少携带“Furina、Mavuika、Escoffier、Ineffa”中的其中1名角色。
