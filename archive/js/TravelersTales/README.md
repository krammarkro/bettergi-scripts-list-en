## 文件结构
```
TravelersTales/  // 主目录
├── assets/       // 资源目录
│   ├── avatars/  // Character头像
│   │   ├── Amber.png
│   │   └── ...
│   ├── icon/     // OCR用图标
│   ├── keymouse/ // 键鼠脚本
│   │   ├── Diluc-1.json
│   │   └── ...
│   └── pathing/  // Path追踪
│       ├── Aino-1.json
│       └── ...
├── data.json     // 识别点数据
├── config.json   // Configuration文件，存放Route的完成状态
├── positions.json // Character点位数据
├── main.js       // 脚本文件
└── README.md     // Guide / Instructions文档
```
### config.json
存放每条Route的完成状态，脚本会Auto 更新  
不存在的Route默认设为false
```json
{
  "Amber-1": true,
  "Amber-2": true,
  ...
}
```
### positions.json
存放Character的大地图点位数据，一般取地图追踪的最后一个点位的坐标  
含有键鼠脚本的Route需添加`hasKeyMouse`属性
```json
[
  { "name": "Amber-1", "x": -1132, "y": 2297 },
  { "name": "Amber-2", "x": -959, "y": 2248 },
  ...
  { "name": "Ningguang-1", "x": 449, "y": -834, "hasKeyMouse": true },
  ...
]
```
